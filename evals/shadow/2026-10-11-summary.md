# First shadow experiment: Claude Sonnet 5.5 per step (2026-10-11)

Each LLM step was run on `claude-sonnet-5-5` while every other step stayed on `claude-opus-5-5`, over the golden set's
12 dev documents (`npm run eval:shadow`), against the replayed baseline. New spend for all four: **$0.64**.
Rule (SPEC-pipeline decision 1): a cheaper model is eligible only if no gated metric gets worse; switching is an
"ask first" change.

| Step | Verdict | Unsafe | Key figures | Routes | Step cost (12 docs) Opus → Sonnet | Live calls (median) |
|---|---|---|---|---|---|---|
| classify | eligible | 0 → 0 | 100% → 100% | 11/12 → 11/12 | $0.135 → $0.068 | 12 (2.1 s) |
| extract | eligible | 0 → 0 | 100% → 100% | 11/12 → 11/12 | $0.820 → $0.408 | 49 (2.7 s) |
| critic | eligible (weak evidence) | 0 → 0 | 100% → 100% | 11/12 → 11/12 | $0.041 → $0.020 | 2 (5.4 s) |
| confidence (read B) | eligible | 0 → 0 | 100% → 100% | 11/12 → 11/12 | $0.295 → $0.145 | 10 (3.2 s) |

All four on Sonnet 5.5 would cost about **$0.65 per pass of the 12 documents instead of $1.29 (about half)**.

## Read B's real job: catching misreads
The gated metrics show read B reads correctly; they do not show it still *catches* read A's mistakes. The injected
misread safety property (every single-digit misread of every key figure on the 8 dev native PDFs) was replayed with each
model as read B: **Opus 5.5: 97 misreads, 0 auto-posted, 96 caught by disagreement; Sonnet 5.5: identical.**

## Recommendation (for the product owner)
- **Switch extract, classify and read B to Sonnet 5.5:** no measured loss, about half the cost of those steps.
- **Keep the critic on Opus 5.5:** only 2 critic calls happen on the dev split, too few to judge, and its most valuable
  case (recovering an under-extracted portfolio) is a held-out document that must not be used for tuning. It costs
  about $0.02 per pass, so there is little to gain.
- **Caveats:** 12 dev documents is a small sample; the held-out measurement after a switch is the real test, and it is
  reported as is. Effort was kept at each step's Opus setting; Sonnet 5.5's effort levels are recalibrated, so an effort
  sweep could save more or recover quality if a later sample shows a gap.
