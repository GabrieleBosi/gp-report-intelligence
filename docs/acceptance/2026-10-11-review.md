## Notes
- Criterion 3 needed a change found during this task: the checklist showed only key figures, so a non-key figure in a
  failed check (EBITDA) could not be corrected on screen. It now lists those figures too ("Other figures in failed
  checks"); they never block approval (only key figures do), but a still-failing check keeps the reason mandatory.
- Local `netlify dev` does not serve a function's `included_files` (the pdf.js worker), so pages that are not cached
  cannot be rendered locally; the deployed function renders them (bundle check and live measurement).
- The e2e test writes real decisions. Each run starts from a fresh pipeline run of the document (cached answers, $0),
  so the demo can always bring trap 1 back into the queue by running it again.
