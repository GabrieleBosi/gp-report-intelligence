- **Outage without taking the system down.** The live mock system was not switched off: criterion 5 ran the real
  loader, the real posting log and the real retry endpoint, with only the portfolio system replaced by one that fails.
  The failed attempt is in the live log, labelled as a simulated outage.
- **Found and fixed during the build:** a retry of an already posted run first answered 409; criterion 3 asks for the
  original record, so a posted run is now replayed with the same idempotency key.
- **Clearance comes from the run itself:** an `unchanged` post matches a version an earlier run created, so the Run
  page describes this run's own approval or policy, never the earlier run's.
